**Learning objective:** By the end of this lesson, students understand best practices for accessibility, such as using alt text and ensuring adequate color contrast.

## Alt text
When designing a website, keep in mind the following tips for providing text alternatives:

- **Be concise and descriptive.** The text alternative should accurately convey the purpose or function of the non-text content.
- **Be specific.** The text alternative should provide enough information so that the user can understand the non-text content, even if they cannot see or hear it.
- **Be consistent.** Use the same format for text alternatives throughout your website. This will help users to understand and use your website more easily.
